# 菜品制作详情页设计文档

**日期：** 2026-04-09  
**项目：** QuickBite 小程序  
**设计者：** AI Assistant

---

## 1. 概述

### 1.1 目标

设计一个菜品制作详情页，用于记录和展示菜品的制作方法，包括用料（原材料、调料）和制作步骤。

### 1.2 使用场景

- **主要场景：** 个人菜谱记录，记录菜是怎么制作的
- **用户：** 自己使用，作为展示页面
- **需求：** 有扩展性，方便后续增加内容

### 1.3 核心功能

1. 菜品基本信息展示（名称、简介、图片）
2. 备菜准备区域（原材料 + 调料）
3. 制作步骤时间线（动作 + 用时 + 火候）
4. 图片可选显示（支持占位图）

---

## 2. 设计方案

### 2.1 整体布局

采用**经典菜谱布局**，信息层次清晰，符合阅读习惯：

```
┌─────────────────────────────┐
│  Header: 菜品制作详情         │
├─────────────────────────────┤
│  📷 菜品图片（可选/占位图）    │
│  菜品名称 + 简介              │
├─────────────────────────────┤
│  📦 备菜准备                 │
│  原材料标签网格               │
│  调料标签网格                 │
├─────────────────────────────┤
│  🍳 制作步骤                 │
│  Vant Steps 垂直时间线        │
└─────────────────────────────┘
```

### 2.2 页面尺寸

- 宽度：375px（标准移动端）
- 高度：812px（适配主流手机屏幕）
- 滚动：支持垂直滚动

## 5. 技术实现

### 5.1 组件选型

基于 Vant UI 组件库：

1. **备菜标签**：使用 `van-tag` 组件
   - 类型：default
   - 样式：自定义背景色和圆角

2. **制作步骤**：使用 `van-steps` 组件
   - 方向：vertical（垂直）
   - 激活状态：active 属性
   - 自定义样式：圆点颜色、连接线

### 5.2 数据结构

```typescript
interface Recipe {
  id: string
  name: string
  description: string
  image?: string
  
  ingredients: {
    category: string
    items: Array<{
      name: string
      amount: string
    }>
  }[]
  
  steps: Array<{
    id: number
    title: string
    duration: string
    heat?: '小火' | '中火' | '大火'
    image?: string
    status?: 'completed' | 'active' | 'pending'
  }>
}
```

### 5.3 响应式设计

- 固定宽度 375px，适配移动端
- 内容超出时支持垂直滚动
- 标签网格自动换行

## 6. 扩展性设计

### 6.1 当前支持

1. **图片可选**：菜品图片和步骤图片都支持占位图，可选择性显示
2. **标签动态**：食材标签数量可自由增减，自动换行
3. **步骤灵活**：制作步骤数量可动态调整，支持添加图片
4. **分类扩展**：可添加更多备菜分类（如"工具"、"装饰"等）
5. **状态标记**：时间线支持标记当前步骤状态

### 6.2 未来扩展

1. **营养信息**：可添加营养成分卡片
2. **小贴士**：每个步骤可添加注意事项
3. **视频链接**：支持添加制作视频
4. **分享功能**：支持分享菜谱给好友
5. **收藏功能**：支持收藏喜欢的菜谱

## 7. 设计决策

### 7.1 为什么选择经典菜谱布局？

1. **符合阅读习惯**：从上到下的信息流，符合用户阅读菜谱的习惯
2. **信息层次清晰**：菜品信息 → 备菜 → 制作，逻辑递进
3. **扩展性强**：每个区域独立，便于后续添加新模块
4. **视觉舒适**：留白合理，不会让用户感到拥挤

### 7.2 为什么选择 Vant Tag + Vant Steps？

1. **一致性**：与项目现有设计风格保持一致
2. **成熟稳定**：Vant 是成熟的 UI 组件库，经过大量实践验证
3. **易于实现**：组件开箱即用，减少开发成本
4. **可定制**：支持自定义样式，满足设计需求

### 7.3 为什么图片可选？

1. **灵活性**：不是所有菜品都有图片，支持纯文字展示
2. **实用性**：作为个人菜谱记录，重点在内容而非图片
3. **扩展性**：后续可以随时添加图片，不影响整体布局
